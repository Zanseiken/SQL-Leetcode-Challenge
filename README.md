## 🤖 NEW: VLA AI Engineer Job Search Tool

This repository now includes a GitHub repository finder tool for Vision-Language-Action (VLA) AI Engineer job applications!

### What is this?
A Python script that searches GitHub for repositories (< 100 stars) relevant to VLA AI Engineer positions in humanoid robotics. Perfect for building your CV/portfolio!

### Quick Start
```bash
# Install dependencies
pip install -r requirements.txt

# Run the search
python3 github_repo_finder.py

# Check results
cat VLA_GitHub_Repos.md
```
